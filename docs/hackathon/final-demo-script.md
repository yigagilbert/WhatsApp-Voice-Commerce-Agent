# Katale AI — final demo script (≈ 7 minutes)

**Katale AI: an AI commerce operations agent that turns WhatsApp text and voice into trusted workflows — ordering, payment, fulfillment, tracking, disputes and analytics.**
Language: English. Payments: PayPal Sandbox (test money only).

## Before you start

1. Production is healthy: `ssh deploy@217.65.145.220 'cd /opt/apps/katale-ai && docker compose ps'`
   shows every service `healthy`, and `docker compose logs --tail=5 whatsapp` shows `client ready`.
2. Optional clean slate (deletes demo orders and payments, keeps everything else):
   `docker compose run --rm -e DEMO_RESET_ALLOWED=true api node dist/demo-reset.js --confirm kampala-crafts`.
3. Open https://kataleai.space and sign in. Keep **Overview**, **Orders**, **Analytics** and **Activity** in tabs.
4. Have the merchant phone (WhatsApp) and a second device with the PayPal Sandbox **Personal** buyer.

## Scenes

| #   | Scene                        | Do                                                                                                                                                                                                                                                                          | Say                                                                                                                                                                                                                                                                                   |
| --- | ---------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | Problem (20 s)               | —                                                                                                                                                                                                                                                                           | "Small businesses already sell in chats. Orders arrive as voice notes; totals, payment links and bookkeeping are manual."                                                                                                                                                             |
| 2   | Merchant voice (30 s)        | 🎙️ _"Create an order for Sarah for ten handmade baskets at twelve dollars each and add twenty dollars shipping."_                                                                                                                                                           | "The merchant just talks."                                                                                                                                                                                                                                                            |
| 3   | AI commerce (30 s)           | Show the reply: _Draft order ORD-… · 10 × Handmade Basket @ $12.00 — $120.00 · Shipping — $20.00 · Total — $140.00 · Reply CONFIRM 4821…_                                                                                                                                   | "The AI understood the sale; the **backend** looked up Sarah and the catalog and calculated every number."                                                                                                                                                                            |
| 4   | Safety (20 s)                | Type `CONFIRM 4821`                                                                                                                                                                                                                                                         | "Money never moves on the AI's word. Approval is typed, bound to this exact order, single-use, and expires. A spoken 'confirm' is refused."                                                                                                                                           |
| 5   | PayPal (40 s)                | Open the link on the second device, pay as the Sandbox buyer                                                                                                                                                                                                                | "A real PayPal checkout, in Sandbox." Show the success page with order and amount.                                                                                                                                                                                                    |
| 6   | Notification (15 s)          | WhatsApp: _✅ Payment received · Order · Customer · Amount_                                                                                                                                                                                                                 | "A verified PayPal webhook marked it paid and told the merchant once."                                                                                                                                                                                                                |
| 7   | Business intelligence (30 s) | 🎙️ or type _"How much have I sold this week?"_, then _"How much did voice orders generate?"_                                                                                                                                                                                | "Answers come from the database, not from the model's memory."                                                                                                                                                                                                                        |
| 8   | AG Grid dashboard (60 s)     | **Overview**: revenue, paid orders, voice vs text. **Orders**: filter _Paid_, sort by amount, open the order (items, PayPal status, trace). **Analytics** (AG Studio): the Sales overview; ask the assistant _"Show paid WhatsApp voice orders from this week as a table."_ | "AG Grid gives operational visibility; AG Studio lets the merchant build views by asking."                                                                                                                                                                                            |
| 8b  | Shipment and dispute (2 min) | See [shipment-dispute-demo.md](shipment-dispute-demo.md): "Mark ORD-… as shipped with DHL tracking 123456789" → `SHIP` code → tracking at PayPal; Sandbox buyer opens a dispute → ⚠️ notice → "Review the dispute" → `SUBMIT` code                                          | "After the sale, Katale runs operations: fulfillment and disputes, with the same rule — AI prepares, the merchant approves, PayPal executes."                                                                                                                                         |
| 9   | Architecture (30 s)          | **Activity** → _View trace_ on the order                                                                                                                                                                                                                                    | "WhatsApp → voice/AI → commerce tools → merchant approval → PayPal → AG Grid analytics, one trace ID. We used APIMatic's PayPal Context Plugin to review our PayPal integration." (only if the APIMatic review is completed — see [apimatic-integration.md](apimatic-integration.md)) |

## If something goes wrong

| Problem                  | Do this                                                        |
| ------------------------ | -------------------------------------------------------------- |
| Voice note slow          | The 🎙️ acknowledgement appears after 2.5 s; replies take 4–9 s |
| "I heard: …" read-back   | Type `YES` if it's right                                       |
| WhatsApp unavailable     | Run scenes 2–7 in the **Agent console** (same pipeline, typed) |
| Buyer can't pay          | Show an earlier paid order in Orders and its trace in Activity |
| Analytics assistant slow | Show the default Sales overview and use drag and drop          |
