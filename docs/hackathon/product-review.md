# English product review (2026-10-07)

A review of the English text and voice product before polishing, and what was done about each gap.
English is the supported language. Luganda and other local languages are frozen (experimental).

| Area                     | Gap found                                                                                              | Change                                                                                                                                                          |
| ------------------------ | ------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Merchant journey**     | A repeated `CONFIRM 4821` answered "nothing waiting", which looked like a failure                      | Replies with the existing request's status and link; never re-executes                                                                                          |
|                          | `CANCEL` left the draft as an open `DRAFT` forever                                                     | Draft is discarded (`CANCELLED`) and the reply names it                                                                                                         |
|                          | PayPal outage answered "an unexpected error occurred"                                                  | "I couldn't create the payment request right now. Your order has not been charged." Order stays a draft                                                         |
|                          | Error copy scattered across files                                                                      | Confirmation and error copy centralised in `copy.ts`                                                                                                            |
| **Buyer journey**        | Return/cancel pages were bare text with no order details                                               | Designed success, processing, declined and cancelled pages with merchant, order and amount; cancel offers "Return to PayPal"; Sandbox badge; no IDs or payloads |
| **Agent UX**             | Clarifications could name tool fields; no rule for "Did you mean…?"                                    | Natural questions ("How many coffee gift packs should I add to Sarah's order?"); explicit did-you-mean rule                                                     |
|                          | No tools for "which orders are unpaid?", "today's orders", "last payment", "how much has Sarah spent?" | `find_orders` (replaces `list_recent_orders`), `list_payments`, `get_customer_summary`                                                                          |
|                          | Conversation history unbounded in time (old topics leaked into new requests)                           | Last 12 messages within 6 hours                                                                                                                                 |
| **Voice UX**             | A misheard product ("buckets") could be priced as a custom item                                        | Voice drafts refuse near-miss products: "Did you mean Handmade Basket?" (text still warns)                                                                      |
|                          | STT failure copy                                                                                       | "I couldn't understand that voice note. Please try again or send the request as text."                                                                          |
|                          | Acknowledgement                                                                                        | Kept: English voice → reply is 4–9 s, so the 2.5 s acknowledgement is useful; fast replies skip it                                                              |
| **Analytics**            | Only revenue / outstanding / top items by quantity                                                     | Paid orders, average order value, product revenue share, top customers, revenue by source (WhatsApp voice / text / console)                                     |
|                          | No way to tell voice orders from text orders                                                           | `Order.inputMode` (TEXT / VOICE), backfilled from audit traces                                                                                                  |
| **Dashboard**            | Plain HTML tables with no sorting/filtering; four cards; raw status codes                              | AG Grid on four pages, six KPI cards, deterministic highlights, readable status labels, order detail panel                                                      |
|                          | No signal that payments are test payments                                                              | "PayPal Sandbox · test payments" badge                                                                                                                          |
| **Payments**             | Activity lacked "webhook received" and "merchant notified" events                                      | `webhook.received` (signature verified) and `notification.sent` audited under the trace                                                                         |
| **Audit**                | Activity was a table of codes and JSON                                                                 | Plain-language timeline tagged AI interprets / Backend verifies / Merchant approves / PayPal executes                                                           |
| **Sponsor integrations** | AG Grid was only "AG Grid-shaped"; APIMatic unused                                                     | AG Grid Community + AG Studio with AI assistant; APIMatic: see [apimatic-integration.md](apimatic-integration.md)                                               |
| **Demo readiness**       | No way to return to a clean demo                                                                       | `demo:reset` (guarded, Sandbox only)                                                                                                                            |
